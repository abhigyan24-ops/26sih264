## 1. Summary of Changes

Task F07 completed the login interface redesign and motion token standardization in accordance with the Civic Ledger design specifications:

1. **Two-Column Statutory Login Page (`frontend/src/pages/LoginPage.tsx`)**:
   - Left Column:
     - Clear institutional headline and statement of purpose for CaseNexus.
     - Highlighted three foundational pillars: Cross-Bureau Overlap Engine, Air-Gapped Privacy Boundary, and Statutory SLA Compliance.
     - Transparent, honest disclaimer: "Notice: Prototype Implementation · Operates with synthetic demonstration data."
   - Right Column:
     - High-contrast card with subtle glass treatment (`bg-[#FFFFFF]/95 sm:backdrop-blur-md border border-[#DAD6CC] shadow-lg`) and solid fallback for non-backdrop environments.
     - Subtle dot-grid paper background pattern (`radial-gradient(#DAD6CC 1.2px, transparent 1.2px)`).
     - Clean inputs with IBM Plex Mono/Sans typography, password visibility toggle (`Eye` / `EyeOff`), and structured error banner (`#FDECEA` / `#B42318`).
     - Quick demonstration officer access buttons (`admin`, `rb1`, `pgrc1`, `ro_north`).
     - Strict safety contract compliance: identical login mutation, local token storage, and root redirect (`navigate('/')`).
   - Note on Lenis: As instructed in Section 5 ("If login has no scrolling content, skip Lenis entirely: smooth scroll on a one-screen page adds nothing"), Lenis was omitted as the login page cleanly fits the viewport without scrolling.

2. **Standardized Motion Tokens (`frontend/src/ui/motion/index.ts`)**:
   - Motion duration scale: Fast (120ms), Normal (200ms), Slow (320ms).
   - Easing curves: `easeOut` (`[0.16, 1, 0.3, 1]`) and `easeIn` (`[0.7, 0, 0.84, 0]`).
   - Reusable motion variants: `fadeInVariants`, `staggerContainerVariants` (30ms stagger, max 8 items), `staggerItemVariants`, and `dialogMotionVariants`.
   - Full compatibility with user `prefers-reduced-motion` settings.
