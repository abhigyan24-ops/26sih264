## What changed
- **Database Schema Migration 070 (`db/migrations/070_ingestion.sql`):**
  - Added `source` (TEXT) and `source_case_id` (TEXT) columns to `cases` table.
  - Added unique partial index `uq_cases_source_case_id ON cases(source, source_case_id)` to enforce batch idempotency.
  - Created `import_mappings` table for data-driven column mapping storage per source system (`rb`, `pgrc`, `regional`).
  - Created `import_logs` table tracking batch imports, total/imported/held/error/duplicate counts, and new overlaps flagged.
  - Created `import_held_rows` table holding unresolvable or ambiguous institution rows for officer review.
- **Ingestion Pipeline Services (`backend/app/services/ingestion/`):**
  - `mapping.py`: Built column synonym heuristic detection (`guess_mapping`), schema target registry, and database-backed mapping persistence (`get_mapping`, `save_mapping`).
  - `parser.py`: Multi-format tabular file parser supporting CSV (with delimiter sniffing for comma, tab, semicolon) and XLSX (via `openpyxl`).
  - `validator.py`: Comprehensive per-row schema validation checking minimum length, date formatting, category matching, and bureau assignment.
  - `processor.py`: End-to-end batch ingestion engine with dry-run support, idempotency skip tracking, institution resolution through `resolve_detailed` (with automatic holding of low-confidence or ambiguous rows), vector embedding calculation (`embed_one`), case registration, and immediate overlap scanning (`scan_overlaps`).
- **REST API Endpoints (`backend/app/routers/ingestion.py`):**
  - `GET /ingestion/sources`: Exposes supported source systems and target schema fields.
  - `GET /ingestion/mappings/{source}` & `POST /ingestion/mappings/{source}`: Retrieves and persists custom column mappings.
  - `POST /ingestion/detect-headers`: Uploads file to inspect detected headers and preview auto-mapped fields.
  - `POST /ingestion/upload`: Handles multipart file upload supporting `dry_run` simulation and live execution.
  - `GET /ingestion/logs`: Historical import audit log endpoint with pagination.
  - `GET /ingestion/held`: Endpoint to query rows held due to ambiguous institution names.
- **Frontend Batch Ingestion UI (`frontend/src/pages/Import.tsx` & `frontend/src/api/ingestion.ts`):**
  - Integrated under Quiet Government Dashboard design system with 4–6px radii, solid panels, and `.gov-table` styling.
  - 4-step ingestion console: Source selection, CSV/XLSX file upload with drag-and-drop, interactive column mapping with "Save Default" action, and Dry-Run safe mode toggle.
  - Real-time result panel displaying KPI summary strip (Total, Imported, Held, Errors, Duplicates, Overlaps), full validation error table, held row candidate breakdown, and past import history.
  - Registered route `/import` and added "Data Ingestion" navigation link in `Layout.tsx`.
- **Sample Datasets & Verification Scripts (`data/samples/`, `backend/scripts/verify_ingestion.py`):**
  - Created realistic sample CSVs for `sample_rb.csv`, `sample_pgrc.csv`, and `sample_regional.csv` with planted cross-bureau overlap clusters.
  - Verified cross-bureau overlap discovery across RB, PGRC, and Regional files.
- **Automated Tests (`backend/tests/test_ingestion.py`):**
  - 6 thorough test cases verifying synonym heuristics, dry-run safety (zero database writes), error reporting on corrupt rows, institution resolution holding, idempotency deduplication, and API source/history endpoints.
