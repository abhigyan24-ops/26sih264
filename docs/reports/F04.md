## 1. Summary of Changes

Task F04 redesigned the case registration modal and the signature overlap coordination review screen according to the Civic Ledger design specification:

1. **Pure Word Diff Engine (`frontend/src/lib/wordDiff.ts`)**:
   - Implemented a pure, deterministic word-level diff algorithm (`computeWordDiff`) using longest common subsequence (LCS).
   - Full Unicode support for English and Indic / Devanagari scripts (handling Hindi vowels, virama `\p{M}`, and conjuncts via `[\p{L}\p{M}\p{N}]+`).
   - Sane length safety cap (4,000 characters) with a note flag (`wasTruncated: true`) preventing browser thread lockups on massive complaint texts.
   - Zero external library dependencies, zero network requests.

2. **Unit Tests for Word Diff (`frontend/scripts/test-wordDiff.mjs`)**:
   - Comprehensive test suite covering all 6 required scenarios:
     1. Identical text returns all matching tokens.
     2. Fully different text flags all words as removed/added.
     3. Single word changed precisely isolates the changed word.
     4. Empty text handled safely without crashes.
     5. Hindi/Devanagari text accurately tokenized and aligned across conjuncts.
     6. Very long text capped at 4,000 characters with truncation metadata.
   - Tested natively with Node test runner: **6/6 passed (0 failures)**.

3. **WordDiff UI Primitive (`frontend/src/ui/WordDiff.tsx`)**:
   - Projector-ready typography (minimum 16px body text as specified for review rooms).
   - High-contrast word tokens: additions in soft green (`#E6F4EC` / `#067647`) and removals in soft red (`#FDECEA` / `#B42318`).
   - Side-by-side comparison view and unified diff toggle mode.

4. **Register Case Modal (`frontend/src/components/RegisterCaseDialog.tsx`)**:
   - Refactored dialog to Civic Ledger paper surfaces (`#FFFFFF` with `#DAD6CC` borders and `#1F3A5F` primary buttons).
   - Preserved exact 400ms debounce resolution query against AICTE master directory.
   - Replaced shield icon with `Lock` icon on sensitive case flag, including explanatory subtitle ("Restricts cross-bureau visibility and masks personal identifiers in general listings").
   - Added live character counter on grievance description.
   - Result panel (F-D2) features `LevelBadge`, confidence metrics, and deep links to detected duplicates.
   - Strict payload invariance: all `createCase` mutation fields (`institution_name`, `institution_id`, `aicte_id`, `city`, `category`, `bureau_code`, `priority`, `sensitive`, `description`) remain identical.

5. **Overlap Review Screen & Components (`frontend/src/pages/OverlapsPage.tsx`, `OverlapCard.tsx`, `DecisionDialog.tsx`)**:
   - Overlaps page updated with `PageHeader`, `Tabs` (`suggested`, `confirmed`, `dismissed`), confidence filter, designed `EmptyState`, and `ErrorState`.
   - `OverlapCard`: side-by-side comparison integrated with `WordDiff`, `LevelBadge`, probability percentage metric, feature contribution bars (with Civic Ledger categorical colors `#2a78d6` and `#B42318`).
   - `DecisionDialog`: refined modal with lead bureau selector, hold checkbox, dismissal reasons dropdown, note requirement for 'other', and 409 conflict handling.
