## Findings

### T10 (Coordination API)
- **Scoping & Security:**
  - Verified `overlap_scope(user)`: Regional officers strictly restricted to overlaps where both `ia.region` and `ib.region` match their assigned jurisdiction (`ia.region=:region AND ib.region=:region`).
  - Out-of-region overlap access properly returns HTTP 404 (`test_regional_out_of_scope` PASSED).
- **Transaction Safety & Atomicity:**
  - Link confirmation executes row-locking `FOR UPDATE OF l` on `overlap_links` to prevent concurrent decision races.
  - Case `hold_parallel` update, dual `actions` inserts, `alerts` generation, and `audit_log` records run inside one transaction with caller commit/rollback (`test_failure_rolls_back_every_write` PASSED).
  - Double-decision prevention correctly raises HTTP 409 Conflict when attempting to decide a non-suggested overlap.
- **SQL & Parameter Typing:**
  - Avoided psycopg3 untyped `:lvl IS NULL` pitfall by building conditional `where` clauses in `list_overlaps`.
  - Sensitive `issue_key` is strictly excluded from returned projection (`FIELDS`).
- **Validation:**
  - Dismissal reasons validated against enum (`different_issue`, `already_handled_elsewhere`, `data_error`, `other`). Rejects invalid codes and missing notes with HTTP 422.
  - Lead bureau validation enforces selection between participating case bureaus.

### T30 (SLA Risk Service & Scan)
- **Mathematical Soundness:**
  - Pure arithmetic separated cleanly into `risk_from_counts(n, still_open, breached, min_history)`, enabling pure unit testing without DB dependency.
  - Graceful fallback: When closed case sample size $n < \text{min\_history}$, returns descriptive basis `"deadline_only"` with standard SLA proximity alerts.
- **Configuration & Dynamic Registry:**
  - Replaced hard-coded thresholds with dynamic registry lookups `get_param(db, "sla_risk_threshold", 0.6)` and `get_param(db, "sla_min_history", 15)`.
- **Idempotency & Deduplication:**
  - Employs daily `dedupe_key = f"{kind}_{case_id}"`. Repeated scans on the same calendar day correctly increment `skipped_dupes` and generate zero redundant alerts.
- **Role Permissions:**
  - `POST /api/sla/scan` properly guarded by `require_roles("admin")` (verified 403 for officers, 200 for admins).
