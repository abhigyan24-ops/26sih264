## 1. Summary of Changes

Task F06 redesigned the boundary control interfaces and administration surfaces according to the Civic Ledger design specification:

1. **Physical ModeToggle Primitive (`frontend/src/ui/ModeToggle.tsx`)**:
   - Implemented a skeuomorphic tactile toggle switch reflecting hardware boundary controls.
   - Distinct mechanical states:
     - Offline (Air-Gapped Local): soft green channel rim (`#A8E2C2`), flush lever with LED indicator dot (`#067647`), "Local Stub" aperture chip.
     - Online: warm amber channel rim (`#F8B7B2`), active lever with LED indicator dot (`#B42318`), "Online" network aperture chip.
     - Locked / Non-Admin: engraved padlock icon (`Lock`), reduced opacity, keyboard accessible but non-interactive.
   - Smooth 200ms ease-in-out transform on the physical lever with focus rings matching Civic Ledger tokens.

2. **ModeBar Refactor (`frontend/src/components/ModeBar.tsx`)**:
   - Compact header integration rendering per-capability scopes (`global`, `email`, `explain`, `enrich`).
   - Air-Gapped Local badge displayed with `ShieldCheck` when no external calls are enabled (`status.data.no_external_calls`).
   - Preserved all polling query intervals (`['policy']` and `['policy-status']` at 10,000ms).
   - Preserved optimistic update logic, window confirmation on online switch, and automated rollback with alert on mutation error.

3. **Admin Shell & Navigation (`frontend/src/pages/AdminPage.tsx`)**:
   - Header updated with `PageHeader`, title "Statutory Administration & Governance", and officer role badge.
   - Tab navigation implemented with the `Tabs` primitive across the 3 statutory panels:
     1. Privacy & Boundary Policy
     2. Model Evaluation & Benchmarks
     3. Statutory Model Card
   - Designed access restriction screen with `Lock` icon for unauthorized roles.

4. **Privacy & Egress Governance (`frontend/src/components/admin/PrivacyTab.tsx`)**:
   - Capability governance table styled with clean paper surface (`#FFFFFF`), borders (`#DAD6CC`), and integrated `ModeToggle` controls.
   - Immutable Egress Audit Ledger updated with tabular mono figures, formatted ISO timestamps, and status chips for Mode, Outcome, and PII Redaction (`YES` / `NO`).
   - Preserved ledger offset pagination and polling intervals.

5. **Model Evaluation & Benchmarks (`frontend/src/components/admin/EvaluationTab.tsx`)**:
   - Prominent amber banner: "Synthetic prototype telemetry: Metrics reflect generated simulation data rather than real-world operational accuracy."
   - Version selector and model metrics comparison table (Status, PR-AUC, High Precision, Medium Recall).
   - Baseline comparison table and calibration table rendered with mono figures and Civic Ledger borders.
   - False positive and false negative pair tables linking directly to case details (`#<id>`).
   - Model promotion and rollback mutations preserved with confirm dialogs.

6. **Statutory Model Card (`frontend/src/components/admin/ModelCardTab.tsx`)**:
   - Lineage table featuring semantic origin badges: `learned_synthetic` (amber), `default_pending_data` (neutral), `policy` (ink blue), `learned` (emerald).
   - Expandable details for raw parameter metrics JSON inspection.
