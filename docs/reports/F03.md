## 1. Summary of Changes

Task F03 migrated the core operational data screens to the Civic Ledger design language without altering any backend API endpoints, payload structures, pagination contracts, or query keys:

1. **New UI Primitives (`frontend/src/ui/`)**:
   - `KpiStrip.tsx`: Compact metric strip with tabular figures, uppercase labels, and semantic variant borders (`accent`, `danger`, `warning`, `success`).
   - `SlaDue.tsx`: Relative SLA time chips with breach alerts (`Overdue 5d`, `Due Today`, `14d remaining`) adhering to Civic Ledger contrast tokens.
   - `Timeline.tsx`: Vertical movement timeline rail with node icons, timestamps, officer metadata, and formatted remarks.
2. **Dashboard Migration (`frontend/src/pages/DashboardPage.tsx`)**:
   - Replaced legacy dark panels with clean paper surfaces (`#FFFFFF`) and hairlines (`#DAD6CC`).
   - Integrated `KpiStrip` for intake telemetry (Total, Pending, Under Process, Disposed, Transferred, Escalated, Overdue).
   - High-priority overlap coordination banner rendered with critical red styling (`#FDECEA` / `#B42318`).
   - Workload bar chart styled with Civic Ledger categorical palette (`#2a78d6`, `#B42318`, `#5B6068`) and 2px surface gap (`barGap={2}`).
   - Preserved `queryKey: ['dashboard']` with 5s refetch interval and DOM IDs (`#dashboard-refresh-btn`, `#dashboard-retry-btn`).
3. **Cases Register Migration (`frontend/src/pages/CasesPage.tsx`)**:
   - Replaced custom table with `DataTable` featuring sticky headers (`#EFEDE7`), row hover, tabular numbers, and integrated skeleton loading.
   - Preserved `X-Total-Count` pagination and URL sync (`q`, `institution`, `aicte_id`, `bureau`, `category`, `status`, `overdue`, `page`, `limit`).
   - Active filter tags and reset functionality integrated into `FilterBar`.
   - Connected `RegisterCaseDialog` via `open={isRegisterOpen}` with button trigger preserved.
4. **Case Detail Migration (`frontend/src/pages/CaseDetailPage.tsx`)**:
   - Left pane: Metadata header, grievance description box, pre-action sibling notice banner, and vertical `Timeline` for case history.
   - Action recording form preserved with all validation rules, action types, remarks, bureau transfers, and document upload capabilities.
   - Right pane: Attached case documents repository with `downloadDocument` triggers intact.
   - Preserved `queryKey: ['case', caseId]` and all cache invalidations.
5. **Institution 360 Profile (`frontend/src/pages/InstitutionPage.tsx`)**:
   - Clean profile header card with permanent AICTE ID, region, and institution type.
   - Intake telemetry stats strip using `KpiStrip`.
   - "Active Handling Bureaus & Cells" card with multi-unit parallel action alert.
   - Recurrent complaint category chips with badge counts.
   - Complete historical case ledger using `DataTable`.
